# SkinVidCheck 项目结构详解

> 本项目基于 **YOLOv26** 模型进行**皮肤病变检测**（湿疹 vs 痤疮 二分类），并预留扩展到 22 类皮肤病的可能。
> 当前硬件目标：**RTX 5070 12GB** | 操作系统：Windows

***

## 📁 1. 项目

```
d:\SkinVidCheck\
├── MyData/                # 原始标注数据（Label Studio 导出 + 已完成转换）
├── train_data/            # YOLO 训练用数据
├── training_output/       # 训练产物（按时间戳组织）
├── Models/                # best.pt 归档目录（与训练时间戳同名）
├── Test/                  # 环境/功能测试
├── Docs/                  # 项目文档
├── config.py              # 训练配置
├── dataset_splitter.py    # 数据集切分工具
├── yolo.py                # 训练主脚本
├── environment.yml        # Conda 环境依赖
├── README.md              # 项目简介
├── CHANGELOG.md           # 变更日志
├── LICENSE                # Apache License 2.0
└── .gitignore             # Git 忽略规则
```

## 📂 2. 数据目录详解

### 2.1 `MyData/` —— 原始标注仓库

存放从 **Label Studio** 导出的**原始数据**，分两部分：

| 子目录                         | 内容                | 命名规则                           | 标注格式                     | 状态                         |
| --------------------------- | ----------------- | ------------------------------ | ------------------------ | -------------------------- |
| `MyData/images/`            | 原始皮肤图像            | `0_0.jpg` \~ `9_9.jpg`（简单数字）   | —                        | 来源图像                       |
| `MyData/labels/`            | Label Studio 任务结果 | `12`、`100`、`900` 等（任务 ID，无扩展名） | **Label Studio JSON**    | 部分未完成（`is_labeled: false`） |
| `MyData/finish/images/`     | 已完成标注的图像          | `<8位哈希>__images%5C<原文件名>.jpg`  | —                        | 已转换                        |
| `MyData/finish/labels/`     | YOLO 格式标签         | `<8位哈希>__images%5C<原文件名>.txt`  | **YOLO 多边形/OBB**（每行多个坐标） | 已转换                        |
| `MyData/finish/classes.txt` | 类别定义（湿疹、痤疮）       | —                              | —                        | —                          |
| `MyData/README.md`          | 22 类皮肤病对照表        | —                              | —                        | 参考                         |

> 💡 **关键点**：`MyData/labels/` 是 **Label Studio JSON**（待标注/部分完成），`MyData/finish/labels/` 是**已转换为 YOLO 格式**的可训练数据。

### 2.2 `train_data/` —— YOLO 训练数据

由 `dataset_splitter.py` 将 `MyData/finish` 按 **8:1:1** 切分得到：

```
train_data/
├── classes.txt                # 类别：湿疹、痤疮
├── images/
│   ├── train/                 # 训练集图像
│   ├── val/                   # 验证集图像
│   └── test/                  # 测试集图像
└── labels/
    ├── train/                 # 训练集标签
    ├── val/                   # 验证集标签
    └── test/                  # 测试集标签
```
